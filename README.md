# Komaru Tea

Интернет-магазин китайского, японского и индийского чая. Курсовой проект по дисциплине «Веб-программирование»: Django, SQLite, шаблоны и CSS.

## Запуск

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py runserver
```

## Роли

| Логин | Пароль | Роль |
| --- | --- | --- |
| client | ClientTea2026 | Клиент |
| manager | ManagerTea2026 | Менеджер |
| admin | AdminTea2026 | Администратор |

Гость смотрит главную, новости, каталог и контакты и может зарегистрироваться. Клиент оформляет и правит свои новые заказы. Менеджер меняет статусы заказов. Администратор ведёт каталог и новости, регистрирует менеджеров и удаляет клиентов и менеджеров: раздел «Администрирование». Те же модели открыты в служебном разделе `/admin/`.
